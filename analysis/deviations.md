## C1 — 2026-11-20 — SCZ effective sample size scale (data-processing correction, not a plan change)

- Finding: in the PGC3 SCZ European file the `NEFF` column, although described in the header as "effective sample size total", is half the effective sample size. - Effect: SCZ observed-scale h² 0.643 → 0.323 (liability 0.355 → 0.178); genetic correlations and intercepts unchanged (rg is invariant to a constant rescaling of N).
- Results seen: yes (genome-wide LDSC only). The error was noticed from the implausible SCZ heritability in the first `02_ldsc.R` run; the correction follows the documented definition of effective N and does not involve any choice that could favour a result.

## D1 — 2026-11-20 — LAVA input for binary traits (implementation clarification of §3.3)
- Plan section: §3.3 ("Binary traits entered with case and control counts").
- Change: LAVA requires a per-SNP N column in the summary statistics and takes the case proportion from the info file. - Reason: data availability and consistency with §2.2. Local rg is unaffected by this choice; local h² is reported on the observed scale at a case proportion of 0.5.

## C2 — 2026-11-20 — Insomnia: palindromic SNPs without allele frequency (technical correction arising from a data property)
- Plan section: §1 (harmonisation: ambiguous palindromic SNPs removed) and §4.4 (MR harmonisation).
- Finding: the insomnia summary statistics (Watanabe et al., UKB-only file) contain no effect-allele frequency, only MAF. `01_munge.R` removed palindromic (A/T, C/G) SNPs only when MAF > 0.42 and otherwise aligned them by allele labels, which assumes that the file and the 1000 Genomes reference are on the same strand. Without an effect-allele frequency this cannot be checked for palindromic SNPs, so the effect direction of any strand-flipped palindromic SNP would be silently reversed. 1,052,956 palindromic SNPs (MAF ≤ 0.42) remained in the harmonised insomnia file, including 39 of 440 genome-wide significant SNPs (P < 5 × 10⁻⁸) and 256 of 2,444 SNPs at P < 5 × 10⁻⁶; 4 of 1,122,447 HapMap3 SNPs used for LDSC (the HapMap3 weight list already excludes most palindromic SNPs). In addition, `04_mr.R` passed the 1000 Genomes reference frequency to TwoSampleMR where the file frequency was missing, so `harmonise_data` (action 2) could not detect a flip.
- Change: (i) `01_munge.R`: when a file has no effect-allele frequency, all palindromic SNPs are removed (rule recorded per file in `munge_counts.csv`, column `palindromic_rule`); (ii) `04_mr.R`: every direction that includes insomnia is harmonised with `harmonise_data(action = 3)` (all palindromic SNPs removed, recorded as `harmonise_action`); (iii) the insomnia file is re-harmonised and LDSC (`02_ldsc.R`), LAVA (`03_lava.R`, UK Biobank and 1000 Genomes references) and the ten insomnia MR directions are re-run. Pre-correction tables are archived in `results/superseded/pre_C2_insomnia_palindromic/` and are not used.
- QC report: the harmonisation summary stated that allele frequencies correlated with the reference at r ≥ 0.993 in every file. For insomnia this was a correlation of the file MAF with the reference MAF (r = 0.9934), not an effect-allele frequency check, and it cannot detect strand flips. `munge_qc.csv` now records the check type per file (column `af_check`).
- Results seen: no insomnia MR result existed (all ten directions had failed on a coding error before producing estimates). Genome-wide LDSC and LAVA results that include insomnia had been computed and seen; the correction follows from the absence of a frequency column and involves no choice that depends on results. Changes in insomnia LDSC and LAVA results are reported below when the re-run is complete.

## C3 — 2026-11-20 — Possible strand mismatch of palindromic variants in LAVA inputs (technical quality correction)
- Plan section: §1 (harmonisation) and §3 (LAVA).
- Finding: in files that report an effect-allele frequency, `01_munge.R` removes palindromic variants with MAF > 0.42 and aligns the remaining palindromic variants by allele labels; it does not use frequency to infer strand. A small number of palindromic variants have a file frequency on the opposite side of 0.5 from the 1000 Genomes EUR reference, which indicates a possible strand mismatch (both frequencies more than 0.08 from 0.5: Bellenguez 1,362, Chia 687, FinnGen 1,920; ≤ 0.2% of palindromic variants per file). They do not affect LDSC (HapMap3 SNP set) and are handled in MR by `harmonise_data` (action 2), which infers strand from the exposure and outcome frequencies; they remain in the LAVA inputs.
- Change (investigator decision, 2026-11-20): (i) the 1000 Genomes LAVA sensitivity analysis, not yet run, uses inputs from which palindromic variants with MAF ≤ 0.42 and a file effect-allele frequency on the opposite side of 0.5 from the reference frequency are removed (`03_lava.R`, folder `data/lava_sumstats_strandqc/`, counts in `analysis/logs/lava_strandqc_counts.csv`); (ii) the main UK Biobank LAVA analysis is not re-run; instead every locus–pair significant at FDR 5% is re-estimated with the same exclusion (`03_lava.R ukb strandcheck`), and the results are reported side by side with the main estimates in `results.json` under `lava_strand_check` and in `results/tables/lava_strand_check_ukb.csv`. A change of sign or loss of significance at any locus is reported to the investigator before further use. Significance in the check is judged against the family-wise BH cut-off of the main analysis (the largest P declared significant in that family), with the other P values held fixed.
- Results seen: the main UK Biobank LAVA results had been computed and seen; no 1000 Genomes LAVA result existed. The exclusion rule is fixed in advance and does not depend on results.

## C4 — 2026-11-21 — LAVA Monte Carlo reproducibility (technical correction) and presentation of the 1000 Genomes sensitivity result (plan unchanged)
- Plan section: §3 (LAVA), §3.6 (UK Biobank reference, main; 1000 Genomes, sensitivity).
- Finding (i), reproducibility: in LAVA v0.1.5 the bivariate P value (integral.p / bivariate.integral: 10⁴ draws, increased adaptively to 10⁵ for P < 10⁻⁴ and 10⁶ for P < 10⁻⁶) and the 95% CI (ci.bivariate, 10⁴ draws) are computed by Monte Carlo simulation (matrixsampling::rwishart); the univariate test is deterministic. Parallel runs were not seeded per locus, so P values differed slightly between runs (strand check: identical SNP sets and rho at all 84 significant locus–pairs, P values differing by a median 3.4%; one pair, locus 848 MDD × SCZ, sat at the family BH cut-off and crossed it).
- Change (i), investigator decision 2026-11-21: every locus–pair is analysed with a fixed seed, SEED + 1000×LOC + 10×i + j (base SEED 20261120; i, j = trait order), set immediately before run.bivar for that pair, so results do not depend on core count or job order (`03_lava.R`, functions `pair_seed` and `bivar_seeded`). Applies to the main analysis, the strand check and the 1000 Genomes sensitivity analysis. The main analysis is not re-run now; as instructed, the 23 primary-family tests and the borderline pair were recomputed with seeds (`03_lava.R ukb seedcheck`; `results/tables/lava_seed_check_ukb.csv`; results.json "lava_seed_check"): each pair run twice gave identical results; rho unchanged; primary family 0 of 23 at FDR 5% (unchanged; lowest seeded FDR 0.090), 8 nominal (unchanged); locus 848 seeded P 0.022, FDR 0.049 (Monte Carlo SE of P 0.0015). All LAVA runs are seeded in the Gate 3 end-to-end re-run.
- Finding (ii), reference panel: with the 1000 Genomes reference, univariate passes, local h² and the share of loci with univariate P < 0.05 were higher for every trait than with UK Biobank, and 19 primary-family locus–pairs were significant at FDR 5% (UK Biobank: 0).
- Change (ii), investigator decision 2026-11-21: presentation of a sensitivity result; the plan is unchanged. The main analysis remains UK Biobank (§3.6). The 1000 Genomes results are reported in full in the Supplementary as a "reference panel sensitivity analysis" (including the list of FDR-significant pairs), not as findings; Results states in one sentence that local correlation results were sensitive to the reference panel. A descriptive diagnostic (sum of local h² vs genome-wide LDSC h², same scale; `06c_lava_reference_diagnostic.R`; results.json "lava_reference_diagnostic") is added; it is not an inferential test. A causal explanation of the inflation is written only with a peer-reviewed source (Faz 5).
